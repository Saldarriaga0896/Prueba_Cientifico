# Prueba_Cientifico
En este repositorio se almacena el codigo desarrollado para aspirar a la vacante de analitico 4 (cientifico de datos) en el grupo bancolombia

Pasos para instalar y ejecutar el proyecto. Los siguientes pasos se deben ejecutar en una ventana de comandos luego de haber clonado este repositorio.

- 1. Crear un ambiente virtual de python. Se recomienda usar python 3.9 o superiores.

python -m venv venv

En caso de no tener instalada la libreria virtualenv, realizar primero el siguiente paso 

python -m pip install virtualenv

- 2. Activar el ambiente 

.\venv\Scripts\activate

- 3. Actualizar pip

python -m pip install pip -U

- 4. Instalar las dependencias

python -m pip install -r requirements.txt

- 5. Ejecutar el proyecto

python main.py
